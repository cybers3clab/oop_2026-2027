# Programmazione a Oggetti in Java – A.A. 2026/2027

In questa repository trovate il codice mostrato durante il corso.

## Struttura

```
oop_2026-2027/
├── lezioni/         codice delle lezioni
└── esercitazioni/   codice delle esercitazioni
```

Il codice si trova in `src/main/java` di ciascuna cartella (lezioni ed esercitazioni).

## Cosa serve

- **JDK 25**
- Un IDE: **IntelliJ IDEA** (consigliato), Eclipse o VS Code

## Come usarlo

1. Scaricate la repository:
   ```
   git clone https://github.com/cybers3clab/oop_2026-2027.git
   ```
   Se non usate Git: pulsante verde **Code → Download ZIP**.

2. Aprite la cartella nell'IDE:
    - **IntelliJ**: File → Open → selezionate la cartella `oop_2026-2027`
    - **Eclipse**: File → Import → Maven → Existing Maven Projects
    - **VS Code**: aprite la cartella con l'estensione *Extension Pack for Java*

3. Aprite un file `.java` contenente il `main` e avviatelo con il pulsante ▶.

Non serve nessuna configurazione: l'IDE prepara il progetto da solo.

## Aggiornamenti

Il codice viene aggiunto dopo ogni lezione. Per scaricare le novità:

```
git pull
```

## Consiglio
Se volete fare delle prove, **copiate il codice in un vostro progetto invece di modificare questi file**, così `git pull` funzionerà sempre senza conflitti.
